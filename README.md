# Ein Hof, viele Wege

Interaktiver Startseitenentwurf für die Freie Schule Untertaunus. Fünf unterschiedlich bemalte Doppeltüren führen zu illustrierten Einblicken. Der Rundgang verbindet die Stationen in fester Reihenfolge.

## Lokal ansehen

```sh
python3 -m http.server --directory docs 4178
```

Öffne danach <http://localhost:4178>. Die Seite verwendet HTML, CSS, JavaScript und lokal gespeicherte SVGs und Schriften. GitHub Pages veröffentlicht `main:/docs` ohne Build-Schritt.

## Materialien

Hof, Türen und Räume sind eigenständige Illustrationen. Die Bereichslinks, die Aufnahme und der Kontakt führen zur [bestehenden Schulwebsite](https://www.freie-schule-untertaunus.de/). Die Schriften Fraunces und Source Sans 3 stehen unter der SIL Open Font License. Die Lizenztexte liegen bei den [Schriftdateien](docs/assets/fonts).
